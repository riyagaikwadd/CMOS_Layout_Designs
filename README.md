# CMOS-Layout-Designs
CMOS Layout Designs
A collection of CMOS circuit schematics, custom layouts, and verification results implemented using Cadence Virtuoso as part of my VLSI design projects and practical learning.  

This repository includes transistor-level circuit designs, standard cell layouts, and physical verification results using UMC 180 nm CMOS technology.  


🛠️ Tools & Technology    
EDA Tool: Cadence Virtuoso  
Technology: UMC 180 nm CMOS  
Domain: VLSI Design – CMOS Layout  
Verification: Design Rule Check (DRC) and Layout Versus Schematic (LVS)  

🎯 Objectives  
Design and implement CMOS transistor-level circuits.  
Develop custom layouts using Cadence Virtuoso.   
Understand transistor sizing, placement, and routing.  
Perform DRC and LVS verification.  
Gain practical experience in CMOS layout design using UMC 180 nm technology.  

🔍 Design Flow  
Schematic Design: Create the circuit schematic using Cadence Virtuoso.  
Layout Design: Implement the physical layout with appropriate transistor placement and routing.  
DRC Verification: Verify the layout against the technology design rules.  
LVS Verification: Check the consistency between the schematic and layout.   
Documentation: Capture and organize schematic, layout, and verification results.  

📚 Key Learnings  
CMOS transistor-level design  
Custom layout implementation  
Transistor sizing and matching  
Floorplanning and routing  
Design Rule Check (DRC)  
Layout Versus Schematic (LVS)  
Cadence Virtuoso and UMC 180 nm technology
